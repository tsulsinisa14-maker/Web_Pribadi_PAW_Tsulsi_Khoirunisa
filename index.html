    Dokumentasi Teknologi yang Digunakan

    Ringkasan penggunaan Git, npm, TypeScript, Vite, dan environment variables pada aplikasi daftar tugas di atas.

    1. Git dan GitHub

    Git adalah version control system untuk mencatat riwayat perubahan kode. Pada proyek ini saya memakai git commit, git branch / git switch, git merge, git push, dan git pull. GitHub dipakai sebagai tempat penyimpanan repository online, tempat membuat Pull Request, dan sumber deploy otomatis ke Vercel. File .gitignore memastikan node_modules, dist, dan .env tidak ikut terunggah.

    2. npm

    npm adalah package manager untuk Node.js. Konfigurasi proyek ada di package.json.

    • dependencies: paket yang dibutuhkan aplikasi saat berjalan.
    • devDependencies: paket yang hanya dibutuhkan saat pengembangan/build (di sini vite dan typescript).
    • Semantic versioning berformat MAJOR.MINOR.PATCH. Tanda ^ (contoh ^8.3.8) mengizinkan update MINOR dan PATCH, sedangkan ~ hanya mengizinkan update PATCH.
    • npm scripts: npm run dev (server pengembangan), npm run build (build produksi), npm run preview (mencoba hasil build).

    3. TypeScript

    TypeScript adalah JavaScript yang ditambah sistem tipe statis sehingga kesalahan tipe ketahuan sebelum aplikasi dijalankan. Di src/types.ts, src/storage.ts, dan src/main.ts digunakan: tipe primitif (string, number, boolean), array (Task[]), interface Task, type alias dan union type (TaskStatus = 'belum' | 'selesai'), serta generics (loadFromStorage<T>).

    4. Vite

    Vite adalah build tool modern. Saat pengembangan, Vite menyediakan dev server cepat dengan hot module replacement. Saat npm run build, Vite menggabungkan dan meminimalkan kode menjadi folder dist yang siap di-deploy ke Vercel.

    5. Environment Variables

    Konfigurasi disimpan di file .env dan dibaca lewat import.meta.env. Hanya variabel berawalan VITE_ yang dikirim ke browser, jadi variabel itu bersifat publik dan hanya boleh berisi data non-rahasia seperti nama dan versi aplikasi. File .env masuk .gitignore, sedangkan .env.example (tanpa nilai rahasia) diunggah sebagai contoh. Password dan API key tidak pernah ditulis di kode, di .env.example, maupun di website.

    6. Peran Compiler, Transpiler, dan Bundler

    Perbandingan compiler, transpiler, dan bundler
    Istilah Fungsi Pada proyek ini
    Compiler Menerjemahkan kode sumber ke bentuk lain sambil memeriksa kesalahan (misalnya pemeriksaan tipe). tsc memeriksa tipe TypeScript lewat npm run build.
    Transpiler Mengubah kode dari satu bahasa/versi ke bahasa lain yang levelnya setara. TypeScript (.ts) diubah menjadi JavaScript yang dipahami browser.
    Bundler Menggabungkan banyak file dan dependency menjadi sedikit file yang dioptimalkan (minify, tree-shaking). vite build menghasilkan folder dist.
